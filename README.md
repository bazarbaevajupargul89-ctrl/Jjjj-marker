# Jetisý Taxi

Алматы облысы бойынша такси шақыруға арналған адаптивті MVP интерфейс.

## Қазір жұмыс істейтін мүмкіндіктер

- Қайдан/қайда мекенжайын енгізу
- Телефон және жолаушы санын енгізу
- Стандарт немесе Комфорт көлігін таңдау
- Бағаны алдын ала есептеу
- Тапсырыс жасау
- Диспетчер панелінде тапсырысты көру және қабылдау
- Тапсырыстарды браузердің `localStorage` сақтау қоймасында сақтау
- Мобильді құрылғыға бейімделген дизайн

## Іске қосу

`index.html` файлын браузерде ашыңыз немесе:

```bash
python3 -m http.server 8000
```

Содан соң `http://localhost:8000` адресін ашыңыз.

## Маңызды

Бұл — дайын демонстрациялық MVP. Нағыз клиенттерден тапсырыс қабылдау үшін серверлік бөлік қажет: база, авторизация, диспетчер аккаунты, WebSocket/real-time хабарлама, карта API, SMS/WhatsApp және төлем жүйесі. Оларды production-ға шығарар алдында қосу керек.
