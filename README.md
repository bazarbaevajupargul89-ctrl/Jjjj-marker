# MARKER

Заманауи шығармашылық студияға арналған бір беттік сайт.

## Іске қосу

`index.html` файлын браузерде ашыңыз немесе кез келген static hosting-ке (GitHub Pages, Vercel, Netlify) орналастырыңыз.

## Файлдар

- `index.html` — сайт құрылымы мен мәтіні
- `style.css` — адаптивті дизайн
- `script.js` — мобильді мәзір және scroll эффекті

Сайттың мәтіндерін, email-ін және әлеуметтік желі сілтемелерін `index.html` ішінен өзгертуге болады.
